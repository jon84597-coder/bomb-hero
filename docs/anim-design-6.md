# 其餘 6 隻主角色的動作設計稿（v5.94 定案用）

> 這份只寫「要生成什麼動作」。影片怎麼拍、怎麼去背、怎麼對齊，都沿用兔兔／小熊那套管線
> （`art/anim-v2/`：參考圖 → 洋紅首幀 → 5 秒影片 → 去背 → 對齊 1069 → 匯出 12 格 webp）。
> 設計原則：**動作要大、要有個性、要一眼認得出是誰**。每隻角色 4 支影片（走位／待機／舉彈／勝利）。

## 共同規格（每支影片都一樣，不用再談）

| 項目 | 值 |
|------|-----|
| 長度 | 5 秒（768²、24fps → 124 幀） |
| 背景 | 純洋紅 `#FF00C8`，**不可換色**（會變青綠／綠色 → 該支作廢） |
| 首幀 | 用遊戲零件拼的參考圖，角色佔畫面高 84%、垂直置中 |
| 構圖 | **角色不位移**（不要往左右走動、不要鏡頭推拉），原地表演 |
| 臉 | **永遠看得見**（不要被球／手／道具擋住，不要背對鏡頭） |
| 球 | 舉彈那支只出現**一顆**球，圓、完整、跟頭差不多大，不要變形、不要多一顆 |
| 循環 | 首尾姿勢要接得起來（影片會當循環動畫播） |
| 禁止 | 不要加道具、不要加文字、不要換衣服、不要讓角色倒地／趴下 |

## 柴犬 KIKI（有個性的）

- **走位**：跩跩的八字步。下巴抬高、肩膀左右各擺約 12°，每兩步回頭瞥一眼再繼續走。尾巴大幅甩成 S。
- **待機**：不耐煩 → 用後腳抓兩下地板 → 抖一下全身（甩水）→ 歪頭盯著鏡頭（「你好了沒」）。
- **舉彈**：**一手托球在胸前、另一手往外攤開**（「怎樣？」的挑釁手勢），下巴抬高。球在胸口高度、不遮臉。
- **勝利**：雙手舉 V 大笑 → 挺腰 → 單膝跪地捶地一下（得意的收尾）。

## 貓咪 NANA（賤賤的）

- **走位**：貓步（腳踩一字線），身體壓低、尾巴直立勾一下，走得慢而囂張。
- **待機**：舔手背洗臉 → 忽然發現有人在看 → 立刻裝沒事坐好（心虛）。
- **舉彈**：**單手把球舉到頭側上方**，另一手在臉旁邊比手勢（賤），頭微偏。球在頭側、臉露出來。
- **勝利**：伸懶腰拱背 → 定格 → 甩頭撥髮 → 單手比勝利手勢。

## 豬豬 MOMO（非常可愛的）

- **走位**：小碎步快走，肚子左右晃，雙手在胸前小幅度擺（像企鵝），每三步彈一下。
- **待機**：低頭用鼻子左右聞地 → 開心地原地蹦一下 → 雙手揉肚子。
- **舉彈**：**雙手把球舉在頭頂上方，用頭往上頂球**（頂球表演），身體微微左右晃。
- **勝利**：原地轉一圈 → 雙手在頭上比愛心 → 連蹦兩下。

## 熊貓 ZUZU（膽小的）

- **走位**：貼身走法 —— 重心壓低、雙手護在胸前、每兩步東張西望一次。
- **待機**：抱頭發抖 → 偷偷探頭 → 被自己的影子嚇到往後彈一步。
- **舉彈**：**雙手把球抱在懷裡護著**（像護著寶物），頭縮起來但**臉要露在球上方**。
- **勝利**：先愣住兩拍 → 才敢小小聲歡呼（手舉一半）→ 開心地原地滾一圈。

## 青蛙 GUGU（獨特的）

- **走位**：青蛙跳步 —— 蹲 → 蹬 → 落地（每步都是小跳），落地時雙手壓地。
- **待機**：蹲著鼓腮呼吸 → 突然彈舌（抓蟲）→ 舔嘴。
- **舉彈**：**雙手把球托在頭頂、蹲低**（舉重預備姿勢），鼓腮。
- **勝利**：連三次空翻跳 → 落地大字張開手 → 鼓腮大叫。

## 小雞 DODO（特別的）

- **走位**：啄木式快走 —— 每兩步啄一下地，翅膀同時拍兩下。
- **待機**：原地啄地找蟲 → 叼到蟲開心拍翅 → 吞不下咳兩下。
- **舉彈**：**雙翅把球頂在頭上**（像海豹頂球），身體左右晃、腳步小碎步。
- **勝利**：開心連跳 → 拍翅 → 原地轉圈 → 張翅定格。

## 支數與節奏

| 批次 | 角色 | 支數 | 目的 |
|------|------|------|------|
| 批 1 | 柴犬 | 4 | 先驗證「跩跩的」這種動作語彙模型吃不吃得下 |
| 批 2 | 貓咪 + 豬豬 | 8 | 賤／可愛兩極一起驗 |
| 批 3 | 熊貓 + 青蛙 + 小雞 | 12 | 剩下的三隻 |

合計 **24 支**。規則：**一批跑完就停**、任何重跑先問、提示詞先貼給你看再送出。

## 小熊還缺的兩支（見另一份討論）

- `throw`（丟炸彈）：三次失敗（趴地／背對＋球變綠／洋紅底變綠）。
- `hurt`（受傷）：兩版都有異物（臉上橫一根咖啡色棍子）或整個人滑出畫面。

沒做的動作目前會自動退成待機 → 走路，不會掉回零件骨架，所以遊戲照樣能玩。
